## Pourquoi ANTIVYRE ?

Le marché des antivirus gratuits est cassé. Avast, AVG et d'autres ont transformé « gratuit » en « gratuit pour vous harceler jusqu'à ce que vous payiez ». Des millions d'utilisateurs dans le monde entier ne sont pas protégés.

ANTIVYRE a débuté en 2019, disposait d'une bêta fonctionnelle en 2021, et a maintenant été reconstruit de zéro avec **Google Magika** — un moteur d'identification de fichiers par IA offrant 99 % de précision sur plus de 200 types de fichiers.

- **100 % gratuit.** Sans publicité, sans vente forcée, sans niveaux cachés. Les dons sont volontaires.
- **Propulsé par l'IA.** Google Magika identifie le type réel des fichiers, quelle que soit leur extension — il détecte les malwares déguisés que les anciens outils laissent passer.
- **Open source.** GPL v3. Inspectez chaque ligne de code.
- **Porté par la communauté.** Traductions, signatures et fonctionnalités apportées par des utilisateurs du monde entier.
- **La vie privée d'abord.** Rien ne quitte votre machine. Aucune télémétrie, jamais.

## Installation

```bash
git clone https://github.com/FreddyDeveloper/antivyre.git
cd antivyre
pip install -r requirements.txt
python main.py
```
