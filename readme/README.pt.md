## Por que o ANTIVYRE?

O mercado de antivírus gratuitos está quebrado. Avast, AVG e outros transformaram “grátis” em “grátis para incomodar você até pagar”. Milhões de usuários em todo o mundo estão desprotegidos.

O ANTIVYRE começou em 2019, tinha uma versão beta funcional em 2021 e agora foi reconstruído do zero com **Google Magika** — um mecanismo de identificação de arquivos com IA e 99% de precisão em mais de 200 tipos de arquivos.

- **100% gratuito.** Sem anúncios, sem vendas forçadas, sem níveis ocultos. As doações são voluntárias.
- **Impulsionado por IA.** O Google Magika identifica os tipos reais de arquivos, independentemente da extensão — detecta malware disfarçado que as ferramentas antigas deixam passar.
- **Código aberto.** GPL v3. Inspecione cada linha de código.
- **Movido pela comunidade.** Traduções, assinaturas e recursos contribuídos por usuários do mundo todo.
- **Privacidade em primeiro lugar.** Nada sai da sua máquina. Sem telemetria, nunca.

## Instalação

```bash
git clone https://github.com/FreddyDeveloper/antivyre.git
cd antivyre
pip install -r requirements.txt
python main.py
```
